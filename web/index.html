Модели и промпты роутера

Как пользоваться

Здесь настраивается список нейронок оркестра и правила Auto: какая модель отвечает на запрос. Сначала выберите модель роутера — она решает, какой слот взять, когда срабатывает LLM-роутинг (неоднозначные короткие запросы и ваши кастомные auto-слоты).

Слоты

  • Модель — тег Ollama, который реально вызывается.
  • Подпись — как слот выглядит в селекторе Tier.
  • Промпт — текст для роутера: когда выбирать этот слот. Пишите конкретно: типы задач, ключевые слова, чего избегать.
  • Участвует в Auto — роутер может выбрать слот сам. Иначе только вручную или через эскалацию.

Rank

Число «силы» слота для эскалации после самопроверки (чем больше — тем сильнее). Ориентир по умолчанию: tiny=0, mid=1, heavy=2, xlarge/coder=3. При провале ответа оркестр поднимается на слот с большим rank. Одинаковый rank — порядок по id; coder — отдельная ветка для кода.

Добавить нейронку

Сначала ollama pull …, затем выберите модель в форме ниже, задайте id (необяз.), rank, промпт и сохраните. Builtin-слоты (tiny…coder) удалить нельзя — только сменить модель и тексты.

Сохранение

«Сохранить» пишет settings.json и сразу применяет настройки. «Сбросить по умолчанию» возвращает стандартные слоты, промпты и роутер tiny.

Для каждой нейронки — когда Auto её выбирает. Builtin-слоты нельзя удалить; можно сменить модель Ollama и текст промпта. Новые слоты — кнопка ниже.
